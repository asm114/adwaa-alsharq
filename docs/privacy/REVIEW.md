# مراجعة سياسة الخصوصية قبل النشر

الصفحة العامة: `privacy/index.html`؛ دليل ثابت يخدم `/privacy/` مع تحويل `/privacy` إليه على الاستضافة الداعمة للأدلة. لا JavaScript أو اتصالات خارجية أو مصادقة في الصفحة. الروابط نسبية لدعم مسار GitHub Pages الفرعي وVercel. لم نغيّر إعداد الاستضافة الرسمية؛ PROJECT_CONTEXT.md يذكر Pages بينما الكود يدعم Vercel أيضًا.

## أدلة المحتوى

- `index.html`: عميل Supabase وAuth وapp_state/main، التخزين المحلي وIndexedDB، Google Identity Services بنطاق drive.file، نسخ JSON ومشاركة واتساب.
- `customer-portal/portal.js` و`resort/portal.js`: قنوات التواصل العامة.
- `resort/feedback.js`: الملاحظات والمرفقات.
- `PR #165` عند `1c56cadc9cf06f26ba09bfdd4fabc5dec0111d98`: نسخ PostgreSQL المشفر وخطة الجدولة والاحتفاظ غير المفعلة. السياسة لا تفترض دمج الطلب أو تفعيله ولا تعدّل محتواه.

## اعتماد المالك المطلوب

- اعتماد اسم الجهة المسؤولة قانونيًا ووسيلة اتصال خصوصية ثابتة (بريد/عنوان عند الحاجة). مؤقتًا تُحال الطلبات إلى وسيلة الإدارة المنشورة في البوابة؛ يجب التأكد من ظهورها وإمكانية استخدامها. لم نخترع بريدًا أو عنوانًا.
- اعتماد أغراض المعالجة والفئات وممارسات الوصول الفعلية ومشاركة مقدمي الخدمات، وأي متطلبات قانونية/نقل دولي للبيانات تنطبق على المنشأة. لا تعد هذه الصفحة شهادة امتثال أو استشارة قانونية.
- تحديد مدد الاحتفاظ لكل فئة والأساس النظامي وآلية معالجة الطلبات والنسخ المحلية والسحابية. لم نعتمد 30 يومًا أو مهلة حذف أو استجابة غير مثبتة.
- اعتماد وصف استخدام بيانات Google وسياسة المشاركة/الاستخدام المحدود المطلوبة للتطبيق بحسب استخدامه الفعلي ومتطلبات Google الحالية. لا تضمن الصفحة وحدها قبول OAuth؛ يلزم تطابق شاشة الموافقة والنطاق وهوية الجهة والدومين المتحقق منه.
- عند تفعيل PR #165 مستقبلًا، إعادة مراجعة الوصف وفق التنفيذ الفعلي، بما فيه التشفير والجدولة والحذف واختبار الاستعادة؛ لا تعد السياسة الحالية وعدًا بتفعيلها.
- تاريخ المحتوى 2026-10-25 تاريخ صياغة، وليس إثبات نشر. بعد اعتماد السياسة ونشرها في مهمة منفصلة، يُستخدم عنوانها العام الفعلي في إعدادات Google OAuth (مثل `https://adwaa-alsharq.vercel.app/privacy` إن كانت هذه الاستضافة المعتمدة). لا تضبط إعداد OAuth على صفحة لم تنشر بعد.

## النطاق وعدم النشر

أضيف رابط ثابت فقط إلى تذييل التطبيق والبوابتين. لا تغيير لأي منطق بيانات أو أسرار أو SQL. `vercel.json` يعطل نشر فرع هذا الطلب فقط لتجنب معاينة Vercel تلقائية عند الدفع؛ لا يحظر main ولا يفعّل نشرًا. PR #165 يضيف ملفًا بالاسم نفسه لتعطيل فرعه؛ عند مراجعة الطلبين تُجمع مدخلات deploymentEnabled بدل إسقاط أحدها. لم نعدّل أيًا من PR #164 أو #165.

## التحقق المنفذ

- Chromium فعلي محلي، أحجام 375×812 و768×1024 و1440×1000: GET /privacy ينتهي بـ200 على /privacy/، اتجاه RTL، دون تسجيل دخول أو JavaScript أو طلبات خارجية أو تجاوز أفقي. فُحصت لقطة الهاتف بصريًا. هذه محاكاة أحجام وليست اختبار Safari أو جهاز iPad فعلي.
- اختبارات المستودع: 330 ناجحًا؛ اختبارات البوابة المستقلة: 5 ناجحة.
- لا تحقق على الإنتاج أو إعدادات OAuth؛ المسار العام لن يصبح متاحًا على الإنتاج حتى الاعتماد والنشر في مهمة منفصلة.
