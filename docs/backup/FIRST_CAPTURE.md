أُنشئ المجلدان في التشغيل 40315914121، ثم توقف فحص PostgreSQL قبل أي نسخ.

`inspection_report` فقط؛ يتوقف عند غياب المجلد أو تعدده ولا يستدعي الإنشاء.

لا تنزيل كائنات أو dump أو تشفير أو استعادة أو حذف في هذه المرحلة.

التقرير لا يحتوي بيانات العملاء أو أسماء الكائنات أو بيانات الاتصال: فقط
folder_id، حجم قاعدة البيانات وإجمالي Storage وأعداد الملفات والحاويات
وإصدارات الإضافات، وحالة إعداد صورة الاستعادة وتقدير الحجم. يحفظ معرف المجلد

المرحلة التالية تُجهّز بعد قراءة هذه القياسات: صورة استعادة مثبتة digest

Storage بخدمته الرسمية المعزولة؛ استعادة بايتات TAR وحدها ليست دليل تشغيل API.

استبدال Client Secret المكشوف بوابة قبل اعتماد اليومي. راجع خطة الاستبدال
في tools/backup/windows/README.md: لا تعطّل السر القديم قبل اختبار البديل إن
سمح Google بتداخل الأسرار، ولا تغيّر مفاتيح تشفير النسخ أو كلمات مرور PG.

## تشخيص PostgreSQL دون كشف الأسرار

المحاولة الأولى أخفت سبب فشل source_connection؛ لا يمكن استنتاج السبب الجذري
من FIRST_CAPTURE_PREPARATION_FAILED. المسار المحدّث يتحقق محليًا من وجود
الإعدادات واسم المضيف المسموح وهوية pooler والمنفذ 5432 وverify-full، ثم يحمّل
CA PEM نفسها للتحقق من صيغتها، ثم يحاول DNS وTCP دون إرسال بيانات اعتماد.
ينفذ libpq بعد ذلك تحقق TLS الكامل والمصادقة والقراءات داخل معاملة read-only.
نجاح TCP وحده لا يثبت TLS أو المصادقة. لا تغيير تلقائي إلى require أو 6543
أو عنوان IP بديل، ولا إعادة تعيين كلمة مرور أو تغيير صلاحيات/RLS.

| رمز/مجموعة | دلالته والإجراء اللاحق |
| --- | --- |
| PG_CONFIG_MISSING | إعداد مطلوب فارغ؛ مراجعة أسماء الأسرار دون قيمها |
| PG_HOST_INVALID / PG_USER_INVALID / PG_PORT_INVALID | رفض الصيغة/الهوية/المنفذ قبل الشبكة؛ مطابقة Connection الرسمي لنفس المشروع |
| PG_PROJECT_UNCONFIRMED | متغير هوية المشروع لا يطابق الهدف |
| PG_SSLMODE_INVALID / PG_CA_MISSING / PG_CA_INVALID | إعداد verify-full أو ملف CA الرسمي يحتاج تصحيحًا، دون تخفيف TLS |
| PG_DNS_FAILED / PG_DNS_TEMPORARY | فشل حل الاسم، أو فشل DNS مؤقت |
| PG_NETWORK_UNREACHABLE / PG_TCP_REFUSED / PG_TCP_TIMEOUT / PG_TCP_FAILED | فشل شبكة/TCP؛ قد يلزم Session Pooler الرسمي عند غياب IPv6؛ تُجرب عناوين DNS المتاحة دون تغيير الهوية |
| PG_TLS_VERIFY_FAILED / PG_TLS_FAILED | رفض شهادة/اسم/سلسلة الثقة أو تفاوض TLS؛ لا طباعة رسالة libpq |
| PG_AUTH_PASSWORD_REJECTED / PG_AUTH_REJECTED | رفض المصادقة؛ ليس تفويضًا لإعادة تعيين كلمة المرور |
| PG_POOLER_IDENTITY_REJECTED | رد pooler يفيد رفض tenant/user؛ مراجعة اقتران المضيف واسم المستخدم بالمشروع |
| PG_PERMISSION_DENIED / PG_RLS_BYPASS_REQUIRED | نقص صلاحية أو عدم إمكان تغطية كل الصفوف؛ لا نجاح جزئي ولا تعديل صلاحيات تلقائي |
| PG_CONNECTION_LIMIT | حد الاتصالات؛ لا زيادة حدود الإنتاج تلقائيًا |
| PG_DATABASE_TOO_LARGE / PG_VERSION_UNSUPPORTED / PG_TLS_NOT_ACTIVE | بوابة السعة/PG17/TLS بعد الاتصال؛ ليست بالضرورة مشكلة كلمة مرور |
| PG_SOURCE_FAILED | فشل غير مصنف؛ لا تخمين ولا تسريب exception أو DSN |

تُقرأ SQLSTATE قبل مطابقة عبارات libpq المعروفة في الذاكرة فقط. المطابقة
تعطي فئة تشخيص ولا تكشف النص الخام. تُغلق الاتصالات التي تفشل بواباتها.
لا تحتوي السجلات قيم PGHOST/PGUSER أو كلمة المرور أو CA؛ التقرير يُظهر الرمز
الثابت ومرحلة الفشل فقط. السكربت لا يحمل مفاتيح تشفير في هذه المرحلة.

لا تفعيل جدولة أو حذف أو دمج تلقائي، ولا شهادة نجاح نسخ إنتاجي حتى وجود
الحزم المشفرة للمشروعين وأدلة الاستعادة المطابقة.
